
# Flood Risk Prediction using Machine Learning

## Project Overview
A beginner-level machine learning project that
uses a Random Forest Classifier to predict the
Flood class from weather-related input features.

## Dataset Features
- Rainfall_mm
- River_Level_m
- Humidity_percent
- Temperature_C

## Target
- Flood: 0 or 1, as provided in the dataset

## Technologies
- Python
- Pandas
- Scikit-learn
- Random Forest Classifier

## How to Run
Install the required libraries:

pip install -r requirements.txt

Run the project:

python main.py

## Disclaimer
This is an educational project. Predictions are
not suitable for real-world flood warnings.
